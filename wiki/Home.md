# Welcome to the Storage Wiki!

**Storage** is a comprehensive virtual storage system for Minecraft servers. It completely changes how players handle resources, offering mechanics to automatically store mined blocks, MythicMobs drops, and crops.

This wiki provides detailed guides on every feature, from basic commands to the Developer API.

## Core Features

### 1. Main Virtual Storage
Automatically stores mined blocks into a virtual inventory instead of cluttering your real inventory.
- **Auto-pickup**: Mined blocks go straight to storage.
- **Auto-sell**: Supports selling items directly from storage.
- **Transfer system**: Easily send resources to other players.
- **Ground-store**: Pick up items from the ground directly into storage.

### 2. MythicMobs Storage System
A dedicated storage system that automatically stores custom drops from MythicMobs when players kill them.
- **Auto-collection**: Keep rare drops safe without losing them to full inventories.
- **Transfer system**: Easily send MythicMobs items to other players.
- **Integration**: Works flawlessly with all modern MythicMobs versions (4.x, 5.x+).

### 3. Crop Storage System
Specifically crafted for farming enthusiasts. Automatically collects harvested crops into a separate virtual storage.
- Easily manage large-scale farms.
- Separate from main storage to keep inventories clean and organized.
- **Includes all other Storage features** (Auto-sell, Transfer, Ground-store).

### 4. Material Conversion System
Allows players to compress or decompress their stored materials effortlessly.
- **Ingots ↔ Blocks**: Quickly convert stored ingots into blocks and vice versa.
- Save space and simplify bulk actions.

### 5. Crafting System
A dedicated custom crafting feature using items from your virtual storage.
- Craft powerful custom recipes directly via GUI.
- Combine raw materials from standard Storage and MythicStorage.
- Fully customizable outputs (Lore, Enchants, NBT flags, Custom Model Data).

### 6. Event System
Host automated server-wide events right from the plugin.
- **Mining Contests**: Compete to mine the most blocks within a time limit.
- **Double Drop Events**: Global multipliers for all mined resources.
- **Community Events**: Work together towards a global mining goal.

## System Requirements & Compatibility
- **Minecraft Versions**: 1.8.x - 1.21.x
- **Folia Support**: Fully compatible!
- **Soft Dependencies**: PlaceholderAPI, WorldGuard, MythicMobs, LuckPerms, MMOItems, MythicLib, PlayerPoints, Vault.
