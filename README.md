# Storage [1.8.x - 26.x]

Storage is a comprehensive virtual storage system for Minecraft servers that allows players to automatically store mined resources, transfer items between players, participate in server events, and manage their resources through an intuitive GUI system.

## Features

* **Virtual Storage System** - Automatically store mined blocks and resources in a virtual inventory
* **MythicMobs Storage** - Automatically store configured MythicMobs items when players kill mobs
* **Conversion System** - Convert materials between different forms (ingots ↔ blocks) with configurable ratios
* **Transfer System** - Send resources to other players with single or multi-item transfers
* **Event System** - Participate in server-wide mining contests and special events
* **Multi-Version Support** - Compatible with supported Minecraft versions from 1.8.x to 26.x
* **WorldGuard Integration** - Respect WorldGuard region protections
* **PlaceholderAPI Support** - Provides placeholders for integration with other plugins
* **Custom Enchant System** - Custom enchantments for tools with configurable effects, particles, and sounds
* **Special Material System** - Rare materials with custom effects, particles, and sounds that can drop from mining
* **Crafting System** - Convenient crafting using resources stored in Storage
* **Folia Support** - Compatible with Folia-based servers
* **Developer API** - Comprehensive API for external plugin integration

> **Important:** This is a complete rework of the original Storage plugin. If you are upgrading from v1 to v2, you **must reset all configuration files**.

## Quick Start

1. Download the latest available Storage `.jar`.
2. Place the plugin `.jar` into your server's `plugins/` folder.
3. Restart the server.
4. Run `/storage` (alias: `/kho`) to open the Storage GUI.
5. Enjoy!
